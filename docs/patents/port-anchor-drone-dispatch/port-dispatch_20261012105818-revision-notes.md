# 本轮聚焦修订说明

## 本轮保护主线

每次改变货箱分配、船舶访问顺序或机型，都从相同资源快照重新计算全部待执行任务的机体、电池和工位时间轴，并以重排后的交付、电量及占用检查决定调整是否可执行。

权利要求1采用S1获取数据、S2初始构造并调用R、S3每次调整调用同一R、S4独立复算及输出四步骤。模拟退火、三种优先顺序、固定访问点上限、两段充电系数和评价权重没有捆绑为独立项必要算法。

## 时间基准

本轮使用“开始准备=0 s”，第一批准备0—60 s、起飞60 s；船舶窗口相应为[60,460]等。此前港口例使用“首发起飞=0 s”，因此本轮基准时刻比其后移60 s。窗口也同时后移，能耗不变，避免负时间准备区间影响阅读。

## 已执行验证

- 访问顺序反转：总距离仍8000 m，但V1交接完成740 s超过460 s；起飞区间非空也因就绪下界不能执行。
- 电池再次出勤：机体746.667 s可用，电池1534.549 s满电，下一起飞1594.549 s。独立检查拒绝忽略电池就绪的伪可行记录。
- 有限共享工位：P2因工位排队充满2535.958 s，导致P3最早2595.958 s起飞，超过1648.816 s上界；同一库存改换排程顺序后可行。没有把某顺序失败解释为所有方案无解。
- 被拒绝候选后再算基准，结果完全一致；验证相离窗口、工位兼容多电池类型、不同电池—工位充电时长。
- 合并/交换/拆分/改派/移动共41个邻域候选调用完整重排；8个候选通过硬约束及独立检查。仅是人工5船数据的一次邻域检查，未据此给出优化性能优势。

原型只用Python标准库，可以重复运行；报告来自本轮实际执行。整体海事仿真还需真实船舶窗口、设备校准、工位功率和占用、物资分布、海况适用条件及统一对照方法。原论文的山区结果没有作为港口效果。

## 参数来源及限制

示例坐标、窗口、两型机体、电池及工位为人工设定。载荷能耗关系来自已有技术材料，交接功率4 kW及准备/周转60 s没有声称为实测。工位预约采用尾部追加，未实现空隙插入；初始电池本例满电，未使用部分SOC起飞策略。原型远距优先键使用货箱目的地至岸站距离之和，其他优先键和并列规则在代码中给出；这些都是示例实现选择。
